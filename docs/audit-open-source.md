# 独立 API 能力与源码发布审核

当前源码：0.3.2。发布范围复核日期：2026-10-11。本轮使用隔离测试资料，不调用付费模型、不发送真实学生资料，不修改正式资料库。

## 定位与适用范围

知衡是单教师、本机使用、需要教师复核的阅卷与教学反馈工作台。上传、PDF 渲染、题目识别、评分标准整理、作答定位和逐点预批均由应用执行，通过配置的模型 API 独立运行，无需 Codex。人工录分、基础统计、基础报告和本机备份无需模型服务。

| 项目 | 当前能力 | 使用边界 |
|---|---|---|
| 模型连接 | 支持图片、兼容 Chat Completions 的服务 | 地址后追加 `/chat/completions`；不自动探测视觉能力，不保证兼容所有服务参数。 |
| 题目与标准 | 题目数量、小问层级、分值与评分点可编辑 | 提示与知识目录以数学为主；未知题型保留有效字段并提示核对，不猜缺失分值。 |
| 学生与答卷 | 文件名匹配学号或姓名，完整 PDF 跨页定位 | 不按相邻照片编号合卷，不识别卷头身份；同批同学生多文件会阻止，须先合成完整 PDF。 |
| 表格 | 第一个工作表、第一行表头，常见中文/英文身份列，题号宽表及逐题长表 | 学号接受“学号”、`Student ID`、`student_id`、`Student Number`、`student_number`、`number`；姓名接受“姓名”、`Name`、`Student Name`、`student_name`。英文不区分大小写。标题行、多表头、合并姓名列和任意列映射不支持。 |
| 评分与复核 | 共用标准确认、逐点建议、原图证据、教师改分及成绩保护 | 结构合法不代表评分正确；等价解法、特殊部分分、缺页与误读仍需教师核对。算法与代码题尚未完成独立 API 盲评。 |
| 恢复与一致性 | 批次保存、失败继续、草稿恢复；标准、原卷或最终分数变化后旧诊断失效 | 默认串行及每日限额，尚未完成学校规模吞吐测试。 |
| 反馈与导出 | 最终成绩统计、个人与班级报告、Excel 导出、教学与复测 | 单次考试不等同于长期能力。网页版报告通过打印窗口另存 PDF，桌面版直接导出 PDF。 |

计分和统计区分空白、草稿、零分、缺考和不适用。全卷统计仅纳入完整最终成绩；逐题使用该题有效人数。多技能状态可能交叉，不相加，也不直接转成长期掌握率。AI 报告建议须由教师审核，引用合法不保证建议正确。

## 验证记录

当前源码的隔离测试、依赖安装、构建、依赖审核及发布检查由 [Windows / Ubuntu CI](https://github.com/Shhaaawwww/zhiheng-grading/actions/workflows/ci.yml) 执行。CI 不配置模型密钥，模拟响应仅验证工程行为，不作为模型效果证据。

2026-10-09 的 0.3.1 本机工程检查包括：48/48 回归、TypeScript/Vite 构建；独立解压源码后重新安装、再次通过回归与构建；隔离资料目录下的本机启动、健康接口和帮助页面验证。此前识卷保护、英文表头、未知题型字段保留及源码打包检查的修复保留在当前版本。0.3.1 初始公开提交的 Windows 与 Ubuntu CI 亦已通过。

公开帮助的截图使用虚构示例；PDF、图片及元数据在发布前单独复核。自动模式扫描不能识别所有图像个人信息，资源变更后须重新人工核对。凭据检查还比对本机现用凭据与正式名单，报告只保存路径、类别和统计，不记录原值。

生产依赖许可在 `THIRD_PARTY_NOTICES.md` 按锁文件列出，JSZip 选择 MIT 分支。`buffers` 的 npm 包缺许可声明，依据 [Debian 保留的上游授权记录](https://sources.debian.org/copyright/license/node-buffers/0.1.1-2/) 补齐版权与 MIT 全文。

0.3.1 审核时兼容升级后生产依赖告警为零，全量剩余 8 个中等告警，来自 `sprintf-js` 的 Electron 开发可选依赖链。持续集成重新审核当前依赖，结果随 registry 和公告变化；源码测试不代替桌面二进制审计与验收。[官方公告](https://github.com/advisories/GHSA-hp3w-g68c-fv3c)

## 模型效果的既有证据

历史 0.3.0 验证涉及 9 份公开 AP 微积分手写作答：原始 AI 总分 6 份与官方一致、2 份有偏差、1 份暂不定分；教师修订后最终总分一致。结果支持辅助工作流可行，不代表当前模型、算法课或全部学科的准确率。原始交付记录保留在版本历史，当前源码不附历史试卷和实测产物。

模型版本、别名和服务实现可能变化，历史模型名称不能作为今天等效复现的证明。后续固定盲评需覆盖等价解法、复杂度推导、不同合法图算法顺序、无解释部分分、跨页与缺页等场景；分别保留模型原始建议和教师修改，按独立学生记录误判、总分偏差及复核耗时。

本轮没有执行新的付费模型盲评，没有把本机模拟响应当作评分质量证据，也没有宣称任意学科、任意表格布局或双面原图均可自动适应。

## 数据与密钥

应用仅监听本机，不提供公网身份认证。网页版密钥仅保存在进程会话内存；桌面版系统支持时使用 Electron `safeStorage`，不支持时仅保留会话密钥。完整备份不含服务密钥，但包含完整学生与考试资料。

AI 阅卷发送必要页面图片，图片可能含手写身份；学情分析使用精简结构及备注，结构字段不发送姓名学号，名单姓名匹配替换为匿名编号。额外个人备注仍应由教师审查。资料保存在本机不代表 AI 请求不离开电脑。

敏感漏洞通过 [私密漏洞报告](https://github.com/Shhaaawwww/zhiheng-grading/security/advisories/new) 反馈。更多说明见 [SECURITY.md](../SECURITY.md)。
