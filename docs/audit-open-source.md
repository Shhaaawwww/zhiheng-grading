# 独立 API 与开源审核

审核日期：2026-10-09。范围：0.3.1 源码预发布。此次工程检查不调用付费模型、不发送真实学生资料，不修改正式资料库。

## 结论

现有软件可以脱离 Codex，通过配置的模型 API 执行识卷、标准整理、作答定位和逐点预批。可准备“单教师、本机、需要人工复核”的源码试用版。当前不应宣称任意题型、任意表格布局和原始双面照片均可自动适应，也不能保证与聊天助手直接批算法卷的效果相同。

界面、计分结构及成绩列随考试配置生成；模型的正确性取决于图像质量、学科能力、参考答案与给分规则。完整工作流还包含身份确认、页面完整性和人工复核，直接调用一次 API 并不能替代这些步骤。

## 能力与缺口

| 项目 | 当前能力 | 边界 |
|---|---|---|
| 独立运行 | 本地 React/Express/SQLite，桌面 Electron；通过 Chat Completions 请求模型 | 不依赖 Codex，但不兼容所有服务参数和 API 协议；没有自动探测视觉能力 |
| 识卷与题型 | 分批识卷、小问层级、可编辑分值、知识点和评分点 | 提示以数学为主，题型限单选、多选、填空、解答、证明和汇总；未知题型暂按解答保留并提示核对 |
| 学生与扫描 | 文件名匹配学号/姓名；完整 PDF 跨页定位及评阅 | 不按照片数字相邻顺序配对，不读卷头身份；同批同学生多文件会阻止，须先合卷 |
| 表格 | 首工作表、首行表头；常见中文/英文身份列；题号宽表或逐题长表 | 不自动定位标题后表头、选择其他工作表、拼接姓和名或映射任意列 |
| 评分 | 标准确认、每批至多三个评分点、原图证据、缺页保护、人工确认 | 合法结构不代表评分正确；特殊部分分与等价解法仍需教师核对 |
| 可靠性 | 断点续批、无效响应拒绝、教师成绩保护、变更后旧诊断失效 | 默认串行、每日限额；尚未完成学校规模吞吐测试 |
| 数据安全 | 仅本机监听、Host/Origin约束、桌面密钥加密、备份不含设置密钥 | 未提供公网身份认证；阅卷图像可能包含手写身份，备份仍含完整学生资料 |

涉及源码：`server/ai.mjs`、`server/assessment-ai.mjs`、`server/assessment-core.mjs`、`server/scan-batches.mjs`、`server/imports.mjs`、`src/workflows.tsx`、`src/assessment.tsx`。

## 本轮修复

1. 上传前整批检查同一学生多文件冲突，并在界面即时提示；不会先上传一半才报错。不同批次上传新的完整答卷仍可替换，历史保留。
2. 名单与录分表接受常见英文学号、姓名表头，统一大小写处理；学号前导零、零分、空白、名单身份和未知成绩列检查保留。
3. 模型返回未支持的题型时，保留有效印刷分值、知识点、小问关系和来源页，不把整行降为空白；未知题型仍需人工确认，不猜缺失分值。
4. 源码发布收紧文件与资源白名单，写 ZIP 前检查凭据，失败保留原发布包；校验不依赖可被 Python 优化模式关闭的 assert。浏览器现场及测试产物加入忽略规则。
5. 在兼容版本范围内升级依赖，修复生产漏洞；增加源码持续集成与准确的适用范围说明。

## 模型效果证据

历史 0.3.0 验收记录包含 9 份公开 AP 微积分手写作答：原始 AI 总分 6 份与官方一致、2 份有偏差、1 份暂不定分；教师修订后最终总分一致。这支持辅助工作流可行，不代表算法课、中文全部题型或当前模型的普遍准确率。评分点互相依赖，不能当成独立学生扩充样本。

DeepSeek 当前官方说明旧 `deepseek-v4-flash-vision-exp` 别名对应的模型已退休，请求转由新的 Flash 模型处理。因此保留历史报告原始模型和数字，不把其结果当成今天等效复现。[官方说明](https://api-docs.deepseek.com/)

OpenAI 官方支持通过模型 API 输入图像并得到文本，但也列出了小字、旋转、图形和准确性限制。API 具备模态能力不能作为阅卷准确性证明。[图像输入](https://developers.openai.com/api/docs/guides/images-vision)、[视觉限制](https://developers.openai.com/api/docs/guides/images-vision#limitations)

下一步扩大适用范围需以公开或获授权匿名卷建立固定盲评：判断题的无解释部分分、Prim 不同合法起点、算法替代解法、复杂度推导、跨页和缺页分别覆盖；保留原始建议与教师修改，记录误判正确、误判错误、总分偏差及复核耗时。此次未执行新的付费 API 盲评，也未把本机模拟响应当作模型效果证据。
